# 第二阶段核心正确性与叙事一致性治理

日期为 2026-11-23。基于第一阶段诊断与当前代码复核后，本阶段修复 Writer 协议、作者视角传递、剧情事件审核和迁移测试隔离问题。所有验证使用合成数据与隔离 SQLite，不读取作者数据库、小说正文或模型密钥。

## 已修复

- Writer 输出 schema 将正文设为至少一个字符，解析器继续拒绝纯空白正文、缺字段和未知字段。旧的 grounding 分支读取 `events`、`entities` 等 Writer schema 明确禁止的顶层字段，因而从未执行。移除了这组不可达分支与对应误导性测试，保留实际工作的场景覆盖、来源引用和 POV 角色校验。
- 移除了以 `task_coverage` 和 `task_forbidden_hits` 自我申报判定任务完成或违反禁令的重复校验。它们只作为诊断数据保留。质量修复稿复用 Writer 的 JSON 解析和必填字段校验。
- POV 解析顺序现在接受本次作者请求的视角，再读取章节任务视角和写作手册视角。无显式设置时保留第三人称限知默认值。无效视角返回明确领域错误。全自动导演把作者提交的全书 POV 传给 Writer，不再固定为第三人称限知。
- Critic 对章节任务中的每条禁用剧情事件逐项审核。确认发生时必须提交来自当前正文的精确摘录和 Unicode 偏移；确认未发生时不能附带正文跨度。报告绑定稿件指纹并在质量审计时重建。存在必需或禁用事件时，即使项目关闭一般 Critic 设置，也必须通过 Critic 审核。
- 质量审计检查禁用事件协议与报告证据。对当前协议报告移除协议标记、证据或修改摘录会阻止 PASS 被采用。旧评估记录仍可读取，但不匹配当前禁用事件审核协议时无法授权采用。
- Alembic 仅在配置仍指向仓库默认 PostgreSQL 地址时采用环境变量 `DATABASE_URL`。迁移调用方显式传入的临时 SQLite URL 会得到尊重，避免测试误升级到另一个数据库。

## 验证结果

- 专项回归覆盖 Writer、质量门、自动导演、Writer POV、禁用事件证据、评估篡改、SQLite 迁移和卷快照迁移。最终专项运行通过 242 项。
- 完整 API 测试集通过 1373 项，跳过 41 项。跳过项包含需要外部 PostgreSQL 的测试。完整测试在本机隔离 SQLite 文件上运行，没有使用作者数据库。
- SQLite 迁移专项 9 项通过，包括卷快照升级和历史行保留测试。备份、恢复、版本和历史回放相关 API 测试包含在完整 API 回归中并通过。
- Web 生产构建通过，Next.js 编译、类型检查和静态页面生成成功。
- Playwright 使用合成项目测试首页、创建小说向导、项目总览、章节工作台和整本规划。每个页面在 320、390、768、1024、1440、1920 CSS 像素视口下检查，`documentElement.scrollWidth` 与视口宽度一致。320 像素时项目导航可展开。该项只检查响应布局，没有调用模型或触发写作。
- 浏览器开发控制台记录到 `/favicon.ico` 返回 404。该资源问题与本阶段代码无关，没有在本阶段修改。

## 剩余风险

- 精确摘录和稿件指纹只能证明审核引用存在于当前版本，不能证明 Critic 对中文语义判断正确。否定、假设、引用、隐喻、反讽和隐含因果仍可能被误判。语义误判可以造成禁用剧情漏检或合理表达被拦截。
- POV 视角和角色可见信息进入 Writer 上下文，并对视角角色、来源及已知信息做确定性校验，但文本叙述是否始终符合目标人称和限知语气仍依赖模型与评审，尚无独立读者验证。
- 事件证据只覆盖章节任务明确列出的必需事件、伏笔回收和禁用事件。它没有把正文里每一个新事实都自动变成可证明的结构化命题。Writer 的创作自由仍包含无法由当前确定性校验穷尽的事实风险。
- 文风、人物可信度、情感感染力、悬念、节奏与阅读吸引力没有通过本阶段的程序测试得到证明。Critic 的 PASS 不代表读者或编辑认可。
- 本阶段没有调用真实模型，也没有生产 PostgreSQL 环境。41 项跳过测试不构成 PostgreSQL 迁移、并发或生产负载验证。

## 第三阶段前置条件

- 先明确第三阶段要建立中文长篇人工质量基准，还是直接进行多章连续创作实验，并为选择的目标固定范围和停止条件。
- 使用原创、合成或明确授权的中文文本，预先冻结样本版本、模型和提示版本、生成参数、预算上限与失败记录格式。
- 为人物可信度、成长、因果、冲突、情感、悬念、节奏、文风、伏笔及阅读意愿编写可操作标注规则，由独立读者或编辑盲评并保留分歧。
