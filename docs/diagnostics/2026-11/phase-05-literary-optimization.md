# 第五阶段文学效果优化记录

日期：2026-11-23

## 本阶段范围

第四阶段确认系统尚无真实中文小说文本和读者评分，人物可信度、情感、节奏、文风自然度和阅读意愿均未验证。本阶段围绕评分规范中的人物动机、角色声线和行动后果做了小范围实现，复用现有 `Character.voice_profile` 和 Writer、Critic 链路，没有新增 Agent、数据表或模型调用。

这次改动建立了可验证的创作输入和作者编辑入口。它没有证明生成正文因此更好，也没有证明真实读者更愿意追读。

## 已完成改动

- Writer 上下文只为当前场景的有效参与人物投影白名单声线字段，并将这些字段纳入上下文指纹。声线变化会形成新的 Writer 上下文。
- Writer 提示要求将任务已有的欲望、阻力、选择和代价落实到场景行动，且只呈现记录行动支持的后果。它引导模型根据情境变化对白和句式，不强制角色重复口头禅。
- Critic 仅在上下文提供声线偏好时，依据正文对白检查是否符合偏好。无偏好时不创建额外声线标准，不以固定口头禅作为一致性要求。
- 人物详情页可编辑语域、措辞、句长、节奏、直接程度、对白习惯、可选口头表达和避免项。保存后出现明确反馈，重新打开页面仍能读取设置。
- 为避免具体对白携带未公开情节，界面不再收集对白样本，Writer 投影也会过滤旧数据中的 `sample_lines` 和其他未列入白名单的字段。

声线设置由作者逐人物控制，留空时使用原有上下文，不会改变正式世界状态或自动采用流程。

## 验证与证据

### 工程证据

- Writer 单元测试验证当前参与角色的声线进入上下文，秘密字段、未知字段和对白样本不进入 Writer 输入，声线变化会更新上下文指纹。
- Critic 提示测试验证只对显式提供的偏好做文本判断，并且不要求重复口头禅或虚构缺省声线约束。
- 完整 API 测试集通过 `1402 passed, 41 skipped`。跳过项未计为通过。
- Web 生产构建通过，Next.js 编译、类型检查和静态页面生成成功。
- 浏览器使用隔离 SQLite 与合成角色验证了声线保存、成功反馈和刷新回读。未连接外部模型。
- 人物详情页在 320、390、768、1024、1440、1920 CSS 像素下均无页面横向溢出，表单控件边界均处于视口内。用 336 字符合成中文描述检查窄屏排版。320、390、768 像素导航抽屉均可通过 Escape 关闭并把焦点还给打开按钮。
- API 暂停时页面展示读取错误和“重新加载”操作。恢复 API 后点击重试可重新读取人物档案。
- 浏览器记录到已有 `/favicon.ico` 404。断网错误测试也产生了预期的请求错误日志。

详细浏览器验收见 [人物声线响应式与交互记录](../../../logs/usability-qa/phase-05-character-voice-2026-11-23.md)。

### 文学效果证据

文学效果状态仍是 `NOT_EVALUATED`。`research/evaluation/pilot-manifest.json` 仍为 `PLANNED_SYNTHETIC_PILOT`，当前没有 A/B/C 条件生成的正文、真实读者盲评、作者修改时间或 Critic 与读者的一致性数据。本阶段未调用真实模型，也没有真实作品数据。

因此本阶段的证据只支持“创作流程能接收和保存作者指定的声线偏好，并将其传入 Writer 与 Critic”。它不支持“角色声音更有辨识度”“人物更可信”或“小说质量提高”等结论。

## 剩余问题

- 尚未证明声线偏好会稳定改变人物对白，也未测量角色间的声音差异、自然度或对作者修改量的影响。
- Writer 对动机、冲突和行动后果的提示仍是未通过文本比较验证的候选策略。提示理解和执行仍受具体模型、任务与上下文影响。
- Critic 的文字判断没有经过人类校准。它不能代替作者采用判断或读者盲评。
- 固定的 A/B/C 任务尚未生成任何实验正文，复杂世界引擎相对基础写作的收益仍未知。

若要继续验证本阶段策略，需要为 A/B/C 固定同一模型版本、参数、种子和预算，并由至少两位不知道条件的中文读者按第四阶段量表评审。没有明确模型额度和评审数据时，文学收益结论保持待验证。
