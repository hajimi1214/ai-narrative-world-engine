# 0.4.0-rc.1 最终整合与发布门验收

验收日期为 2026-11-24。仓库版本仍为 0.4.0-rc.1。本报告复核前五阶段成果并完成最后一轮候选验收，不创建 GitHub Release 或稳定版标签。

## 发布结论

该仓库可作为本地作者工作台候选版本使用。SQLite/Fake Provider 验收证明了主要软件状态流、改稿、审核、备份恢复和导出行为。实际模型服务下的章节创作和中文长篇文学收益没有验证。因此本次不宣布稳定版发布，也不把工程回归描述为高质量小说能力证明。

稳定版发布阻断项为实际模型供应商的首次配置和真实连接、有限预算下的多章连续生成/暂停/恢复端到端验收，以及真实生成文本的作者或读者质量确认。缺少模型额度、实际服务账户和读者数据时，本报告如实保留这些缺口。

## 当前系统能力

- 本地 Windows 单作者安装，FastAPI、Next.js、SQLite 与启动器。
- 小说创建入口、书级方向、卷与章节任务、人物和世界资料。
- 作者主导卷级创作、自动导演、章节 Writer、Critic 审核、作者编辑、版本历史、批准和采用。
- 自动运行持久化检查点、预算状态、未知用量预留、暂时性错误退避、暂停与恢复。
- 章节候选世界分支、正文事件证据、采用后发布、封卷连续性快照和可选自动跨卷。
- 项目备份、恢复为副本、TXT/Markdown 导出和已批准正文筛选。
- 中文文学研究量表、冻结的 A/B/C 试点设计、盲评包准备、记录验证和离线分析工具。

上述流程的工程实现不保证每个模型都遵守规划，也不保证正文具有读者认可的文学质量。

## 前五阶段整合状态

- **阶段一**建立了架构、研究来源、风险与证据分级。原始诊断问题已在后续阶段重核，不作为当前缺陷清单照抄。
- **阶段二**治理 Writer 输出契约、作者 POV 传递、正文事件证据、采用边界和迁移测试隔离。仍存在中文语义误判风险。
- **阶段三**加入运行检查点、租约恢复、重试退避、未知用量预留与成本状态展示。供应商实际费用和断网后请求计费仍不可由本地状态证明。
- **阶段四**建立 21 维中文文学量表、固定 A/B/C 任务、盲评数据治理与配对分析工具。实验正文、读者分数、修订时间和 Critic 对照均未收集。
- **阶段五**已有作者可编辑人物声线、Writer 场景动机/后果提示及 Critic 声线检查。另修复了 Writer 无法读取当前章节分支中先前场景所形成的 POV 角色知识和记忆。该修复通过上下文与状态隔离测试，但没有真实文本对照，不能宣称文学提升。

## 普通作者是否能完成长篇创作

符合文档环境要求的 Windows 用户可以安装本候选，在本机完成主要作者工作流。Fake Provider 与合成数据证明了从运行、章节状态、修改、审核、备份恢复到导出的软件路径。实际模型生成的兼容性、文本质量、供应商费用和长时间稳定表现尚未由本次测试覆盖，因此目前不能保证作者能稳定完成高质量长篇小说。

关键能力通过等级如下：

- **工程状态和数据路径**：本地 SQLite/Fake Provider 自动化证据。
- **用户界面与响应式布局**：合成数据下的真实浏览器证据。
- **真实供应商写作链路**：未验证。
- **真实读者文学质量**：NOT_EVALUATED。
- **真实成本与修改负担**：UNKNOWN / NOT_COLLECTED。

## 风险与限制

- Critic 的语义判断可能误解否定、反讽、隐含因果、视角和人物语言。
- 作者编辑、证据引用和自动采用检查可以发现部分状态冲突，不能穷尽正文新事实。
- 缺失 usage 的本地预留不等于供应商账单上限，成本仍为 UNKNOWN。
- SQLite 单作者本地部署是目标环境。PostgreSQL 生产行为、多用户负载和云部署未验收。
- 加密项目密钥恢复依赖原 AI_CREDENTIAL_MASTER_KEY，项目备份不包含该主密钥。
- 现有历史回放限制、CSS 构建警告与 FastAPI/SQLAlchemy 弃用警告仍需维护。
- A/B/C 试点条件在现有运行路径中的可比性与模型调用配置尚未经真实实验确认。

## 发布状态与后续决策

当前有可追溯的 0.4.0-rc.1 候选代码，但没有稳定版发布条件所需的真实模型验收或文学效果证据。GitHub main 已包含提交 db7d0a8。没有创建 Release 或标签。后续是否补齐模型额度和评审资源、是否发布该候选或采用其他版本策略，由作者决定。
