# 第五阶段人物声线页面验收

日期：2026-11-23

## 环境

- 使用 Next.js 生产构建和本地 FastAPI。
- API 指向系统临时目录中的独立 SQLite 数据库，数据只有合成项目和合成角色。
- 模型提供方设为禁用，没有真实模型调用、作者数据库或私人小说文本。
- 浏览器通过 Playwright CLI 访问人物详情页。

## 结果

| 视口宽度 | 页面与表单无横向溢出 | 表单控件未越界 |
| ---: | :---: | :---: |
| 320 | 通过 | 通过 |
| 390 | 通过 | 通过 |
| 768 | 通过 | 通过 |
| 1024 | 通过 | 通过 |
| 1440 | 通过 | 通过 |
| 1920 | 通过 | 通过 |

- 320、390、768 像素下打开移动导航，按 Escape 后抽屉关闭，焦点回到“打开导航”按钮。
- 语域字段输入 336 字符合成中文文本时，320 像素页面宽度仍为 320 像素。
- 对合成人物 GET 请求延迟 15 秒后，页面显示“正在加载世界数据…”骨架状态。
- 提交声线偏好后页面显示“表达声线已保存”。重新加载并切换到声线页，表单从隔离数据库读回相同数据。
- 清空 API 响应后页面显示“暂时无法读取人物数据”和“重新加载”。恢复 API 后使用重试按钮成功读取角色。
- 页面没有“认可的对白样本”输入项。

## 限制

访问记录中存在原有 `/favicon.ico` 404。故障状态测试期间的 API 网络错误属于预期注入结果。此次验收验证页面布局、焦点、错误恢复和数据持久化，不验证 Writer 生成效果或真实读者体验。
