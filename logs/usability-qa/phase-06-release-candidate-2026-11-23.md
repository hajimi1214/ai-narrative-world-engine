## 环境与安全边界

- 使用 Python 3.12 锁定依赖环境、Next.js 生产构建和临时目录中的隔离 SQLite。
- 测试数据由程序生成，只有合成作品、角色、场景、章节任务和合成正文。
- AI Provider 为 `disabled`。Writer 假模型只用于 API 集成测试，没有向真实供应商发起请求。
- 启动器 smoke test 从临时工作区调用原 `start-platform.ps1`，工作目录链接到仓库代码，数据库和日志仍写入临时位置。工作区现有日志未被覆盖。

## 工程验证

- `uv sync --locked --extra test --python 3.12` 成功创建锁定 Python 3.12 测试环境。
- `uv lock --locked --offline` 通过，未修改 `uv.lock`。
- `pnpm install --frozen-lockfile` 通过。
- API 全量回归通过 `1402 passed, 41 skipped`，耗时约 321 秒。41 项依赖 PostgreSQL 或未配置的外部服务，不计为通过。
- Web 工具测试通过 `22 passed`，覆盖版本差异、事件证据定位、运行状态显示和串行轮询、后台暂停、超时及恢复。
- `pnpm exec tsc --noEmit --incremental false` 通过。
- `pnpm build` 通过，Next.js 编译、类型检查和静态生成完成。
- 全量 API 测试报告 3680 条既有警告，主要包括 `datetime.utcnow()`、FastAPI `on_event`、Starlette TestClient 与 httpx 的弃用提示，以及 SQLAlchemy 表排序循环警告。没有测试失败。
- 从空的临时 SQLite 启动迁移后，Alembic 当前版本为 `0045_chapter_world_branches (head)`。
- `start-platform.ps1 -NoBrowser` 在临时工作区启动成功，健康检查和首页 readiness 检查通过。
- Fake Provider 集成验收覆盖自动创作、正文采用、项目备份恢复、作者改稿、重新审核，以及恢复后 TXT/Markdown 和仅批准稿导出。
