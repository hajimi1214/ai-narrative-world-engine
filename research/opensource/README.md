# 开源写作系统研究库

此目录是围绕本地单作者长篇小说工作台建立的**设计研究库**。它记录公开的产品行为、持久化边界、版本流程、内容组织方法，以及这些观察怎样转化为本项目的原创实现。

## 使用边界

- 上游克隆位于 [`../opensource-downloads`](../opensource-downloads)，在根目录 `.gitignore` 中排除，不会跟随本项目打包或提交。
- 本轮只浅克隆和静态阅读 README、公开文档、许可证元数据与少量关联实现，用于理解公开设计；没有安装依赖、运行上游应用、复制上游代码、界面、素材或提示词。
- 研究笔记以自己的话重述系统观察，不保存上游的大段原文，也不导入作者作品、数据库、日志、密钥或第三方用户数据。
- 上游提交锁定在 `sources.json` 记录的 commit；重新下载或引用新行为时更新对应 manifest 与笔记。
- 代码库中的 GPL/AGPL/MIT/Apache 条款各自适用于不同项目与依赖。本研究不把上游源码加入产品依赖，也不据此判断项目整体发行许可证；如以后考虑复用或分发代码，应单独进行许可证审查。
